# КБЖУ по фото (PWA)

Современное приложение для примерной оценки КБЖУ еды по фотографии. Фото отправляется в Gemini API, AI распознаёт продукты, оценивает порции и возвращает структурированный JSON; итоговые значения приложение пересчитывает само по формуле `на 100 г × масса / 100`.

Ключ Gemini **никогда** не попадает во фронтенд — он хранится на сервере (секреты Cloudflare Worker или файл `.env` локального Node-сервера).

## Структура проекта

```
kbzhu/                    → фронтенд (статический PWA, раздаётся как есть)
  index.html              → оболочка + meta PWA + splash-экран
  manifest.webmanifest    → манифест установки (иконки, standalone)
  sw.js                   → service worker (офлайн-кэш)
  icon.svg                → векторная иконка
  icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png
  css/style.css           → тема (светлая/тёмная), карточки, анимации
  js/app.js               → экраны, редактирование, дневник, история, статистика
  js/api.js               → единственная точка вызова AI
  js/store.js             → хранение (localStorage: история, цели, настройки)
  js/nutrition.js         → пересчёт КБЖУ
worker/
  worker.js               → Cloudflare Worker (прячет ключ, проксирует в Gemini)
server/
  index.js                → локальный Node-сервер (без зависимостей): статика + API
  package.json
.env.example              → образец переменных окружения
.gitignore
```

## 1. Получение ключа Gemini API

1. Откройте https://aistudio.google.com/apikey и войдите в Google-аккаунт.
2. Нажмите **Create API key**, скопируйте ключ.
3. Храните ключ только в `.env` / секретах Worker, не коммитьте его.

## 2. Вариант А — локальный запуск (Node.js)

Нужен Node.js 18+ (зависимости ставить не нужно, используется только стандартная библиотека).

1. Скопируйте `.env.example` в `.env` (файл уже создан) и вставьте ключ:
   ```
   GEMINI_API_KEY=ваш_ключ
   ```
2. Запустите сервер:
   ```bash
   cd server
   npm start
   ```
   или просто `node server/index.js` из корня.
3. Откройте в браузере **http://localhost:3000** — приложение и API работают на одном адресе.
4. (Приложение само возьмёт API с этого же сервера, но для надёжности проверьте в «Настройках», что адрес сервера = `http://localhost:3000/api/analyze-food`.)

## 3. Вариант Б — публикация (Cloudflare Worker + GitHub Pages)

Сервер-прокси в облаке:

1. https://dash.cloudflare.com → Workers & Pages → Create → Hello World → Deploy.
2. Edit code → вставьте содержимое `worker/worker.js` → Deploy.
3. Settings → Variables and Secrets:
   - секрет `GEMINI_API_KEY` = ваш ключ;
   - переменная `ALLOWED_ORIGIN` = `https://ваш_логин.github.io` (без пути и слэша);
   - необязательно `MODEL` = `gemini-2.5-flash`.
4. Скопируйте адрес вида `https://имя.аккаунт.workers.dev`.

Фронтенд на GitHub Pages:

1. Создайте репозиторий, загрузите **содержимое папки `kbzhu/`** в корень.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Откройте сайт → «Настройки» → вставьте адрес Worker → «Сохранить настройки».

## 4. Установка как приложение (PWA)

На телефоне откройте сайт (или `http://localhost:3000`) в браузере:

- **Android / Chrome**: меню → «Добавить на главный экран» / «Установить приложение».
- **iOS / Safari**: «Поделиться» → «На экран „Домой"».

После установки приложение открывается в отдельном окне без адресной строки, с иконкой и splash-экраном.

## 5. Как это работает

```
Фото (камера/галерея)
  → сжатие до 1024px JPEG (canvas)
  → POST {image, mime, hint} на сервер
  → сервер → Gemini (structured JSON, responseSchema)
  → сервер валидирует JSON → фронтенд
  → пересчёт КБЖУ (на 100 г × масса / 100) + редактирование
  → сохранение в дневник/историю (localStorage)
```

## 6. Возможности

- Камера (`capture="environment"`) и загрузка из галереи.
- Этапы анализа с индикацией.
- Индикатор уверенности: 🟢 высокая / 🟡 средняя / 🔴 низкая (общий и по каждому продукту).
- Редактирование: название, масса, Б/Ж/У; автопересчёт при изменении массы; «+ Добавить продукт».
- Уточняющие вопросы (размер порции), когда AI не уверен.
- Дневник (Завтрак/Обед/Ужин/Перекус) с прогресс-барами и целями.
- История с фото, удалением и повторным открытием.
- Статистика: Сегодня / Неделя / Месяц.
- Светлая/тёмная тема.

## 7. Примечания

- **Значения на 100 г приходят от Gemini** (по справочным данным), а не из локальной пищевой базы; итоги считаются в приложении.
- Заголовок `Origin` можно подделать вне браузера — для защиты включите Rate limiting в Cloudflare (или задайте `ALLOWED_ORIGIN`).
- Для iOS-иконки используется `apple-touch-icon.png` (180×180). Полноценный iOS splash можно добавить через `apple-touch-startup-image` с точными размерами.
- Данные (история, цели, настройки) хранятся в браузере устройства и не синхронизируются между устройствами.
- Модель по умолчанию `gemini-2.5-flash`; при необходимости меняется в `MODEL`.
