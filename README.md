# КБЖУ по фото (PWA)

Приложение для примерной оценки КБЖУ еды по фотографии. Фото отправляется в **DeepSeek Vision** (`deepseek-flash`), AI распознаёт продукты, оценивает порции и возвращает структурированный JSON; итоговые значения приложение пересчитывает само по формуле `на 100 г × масса / 100`.

Ключ DeepSeek **никогда** не попадает во фронтенд — он хранится только на сервере (переменная окружения `DEEPSEEK_API_KEY`).

---

## 🚀 Быстрый старт: Cloudflare Pages (рекомендую)

Здесь сайт и API живут в **одном проекте на одном адресе**, поэтому:
- нет «холодного старта» — сайт открывается сразу;
- в приложении **не нужно** ничего настраивать (поле «Адрес сервера» оставляем пустым).

1. **Загрузите код на GitHub** (весь проект целиком). Ключ не пострадает — `.env` уже в `.gitignore`.
2. Откройте **dash.cloudflare.com** → **Workers & Pages** → **Create** → вкладка **Pages** → **Connect to Git**.
3. Выберите свой репозиторий.
4. На странице настроек сборки укажите:
   - **Framework preset**: `None`
   - **Build command**: оставьте пустым
   - **Build output directory**: `kbzhu`
5. Нажмите **Save and Deploy** и дождитесь надписи *Success*.
6. Откройте проект → **Settings** → **Environment variables** → **Add**:
   - **Name**: `DEEPSEEK_API_KEY`
   - **Value**: ваш ключ DeepSeek
   - Environment: **Production**
   → **Save**.
7. Перезапустите деплой, чтобы переменная подхватилась: **Deployments** → у последнего деплоя **⋯** → **Retry deployment**.
8. Готово! Откройте адрес вида `https://имя-проекта.pages.dev` — сайт и анализ работают с одного адреса.

> Файл [`functions/api/analyze-food.js`](functions/api/analyze-food.js) Cloudflare Pages подхватывает сам — это и есть API. Секреты в нём не хранятся.

## 🔑 Получение ключа DeepSeek

1. https://platform.deepseek.com → войдите или зарегистрируйтесь.
2. В левом меню **API Keys** → **Create API Key** → скопируйте ключ.
3. Вставляйте его только в переменные окружения (Cloudflare / Render / `.env`) — не в код.

> Фото умеет понимать только модель `deepseek-flash` (стоит по умолчанию). Обычные текстовые модели DeepSeek картинки не принимают.

## 💻 Локальный запуск (для проверки на компьютере)

Нужен Node.js 18+. Зависимости ставить не нужно.

1. Вставьте ключ в [`.env`](.env):
   ```
   DEEPSEEK_API_KEY=ваш_ключ
   ```
2. Запустите:
   ```bash
   npm start
   ```
3. Откройте **http://localhost:3000**.

## 🐢 Альтернатива: Render

Работает так же (сайт + API на одном адресе), но на бесплатном тарифе сервис «засыпает» после ~15 минут простоя — первый заход может ждать 30–60 секунд. Если это не мешает:

1. render.com → **New** → **Blueprint** → выберите репозиторий (файл [`render.yaml`](render.yaml) уже есть).
2. После деплоя: **Environment** → добавьте `DEEPSEEK_API_KEY`.

## 📦 Что куда выкладывать

| Что | Куда | Зачем |
|---|---|---|
| Весь код (`kbzhu/`, `functions/`, `server/`, `worker/`, `README.md`, `render.yaml`, `package.json`, `.env.example`, `.gitignore`) | **GitHub** | хранение кода, откуда Cloudflare/Render его берут |
| `DEEPSEEK_API_KEY` (сам ключ) | **Cloudflare → Environment variables** (или Render / локальный `.env`) | секрет, в GitHub его нет |
| Сайт + API | **Cloudflare Pages** (одна ссылка на всё) | быстро, без холодного старта |
| `.env` (с настоящим ключом) | **только ваш компьютер** | локальный запуск, в git не попадает |

**Можно ли всё положить в GitHub?** Да — весь *код* нужно положить в GitHub. Нельзя только сам **ключ** (`DEEPSEEK_API_KEY`): GitHub не умеет хранить секреты и выполнять серверный код. Поэтому ключ и «живой» сервер живут на Cloudflare, а GitHub — хранилище кода.

## Структура проекта

```
kbzhu/                          → фронтенд (статический PWA). ЭТУ папку отдаёт Pages
  index.html                    → оболочка + meta PWA + splash
  manifest.webmanifest, sw.js   → установка как приложение и офлайн-кэш
  icon.svg, icon-192/512.png, icon-maskable-512.png, apple-touch-icon.png
  css/style.css                 → тема (светлая/тёмная), карточки, анимации
  js/app.js                     → экраны, редактирование, дневник, история, статистика
  js/api.js                     → вызов AI (сам определяет адрес сервера)
  js/store.js                   → хранение (localStorage)
  js/nutrition.js               → пересчёт КБЖУ
functions/api/analyze-food.js   → API для Cloudflare Pages (прячет ключ, ходит в DeepSeek)
server/index.js                 → то же самое для локального запуска / Render (без зависимостей)
worker/worker.js                → то же самое для отдельного Cloudflare Worker
render.yaml, package.json       → деплой и запуск
.env / .env.example             → ключ (локально) / образец
.gitignore                      → защита ключа
```

## Возможности

- Камера и загрузка из галереи; сжатие фото до 1024px.
- Этапы анализа, индикатор уверенности 🟢/🟡/🔴 (общий и по каждому продукту).
- Теги продукта: сырое/варёное/жареное/запечённое, «скрытый жир/соус».
- Редактирование: название, масса, Б/Ж/У; автопересчёт; «+ Добавить продукт».
- Уточняющие вопросы с вариантами ответа под сам вопрос и кнопкой «Свой ответ».
- Дневник (Завтрак/Обед/Ужин/Перекус) с целями и прогресс-барами.
- История с фото и удалением; статистика Сегодня/Неделя/Месяц.
- Светлая/тёмная тема; установка как приложение (PWA).

## Примечания

- Значения на 100 г приходят от DeepSeek (по справочным данным), итоги считаются в приложении.
- Модель по умолчанию `deepseek-flash`, меняется переменной `MODEL`.
- Данные (история, цели) хранятся в браузере устройства и не синхронизируются между устройствами.
