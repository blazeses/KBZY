# КБЖУ по фото (PWA)

Современное приложение для примерной оценки КБЖУ еды по фотографии. Фото отправляется в **DeepSeek Vision** (`deepseek-flash`), AI распознаёт продукты, оценивает порции и возвращает структурированный JSON; итоговые значения приложение пересчитывает само по формуле `на 100 г × масса / 100`.

Ключ DeepSeek **никогда** не попадает во фронтенд — он хранится только на сервере (переменная окружения `DEEPSEEK_API_KEY`).

---

## 🚀 Самый простой способ — Render (бесплатно, один сервис)

На Render приложение отдаёт и сайт, и API с одного адреса. Настраивать адрес сервера в приложении **не нужно** — оно само использует свой домен.

1. **Залейте весь проект в GitHub** (репозиторий с исходниками). Ключ не пострадает: `.env` уже в `.gitignore`.
2. Зайдите на **render.com** → зарегистрируйтесь (бесплатно) → **New** → **Blueprint**.
3. Подключите GitHub и выберите репозиторий — Render сам прочитает [`render.yaml`](render.yaml).
4. Нажмите **Deploy**. После деплоя откройте сервис → **Environment** → добавьте переменную:
   - `DEEPSEEK_API_KEY` = ваш ключ (см. ниже «Получение ключа»).
5. Готово: откройте адрес вида `https://kbzhu.onrender.com` — приложение работает. На телефоне: «Добавить на главный экран».

> Free-план Render «засыпает» после ~15 минут простоя, первый запрос может ждать ~30–60 сек (холодный старт).

---

## 💻 Локальный запуск (Node.js, для разработки)

Нужен Node.js 18+. Зависимости ставить не нужно.

1. Вставьте ключ в [`.env`](.env):
   ```
   DEEPSEEK_API_KEY=ваш_ключ
   ```
2. Запустите:
   ```bash
   npm start        # или: node server/index.js
   ```
3. Откройте **http://localhost:3000**.

## ☁️ Альтернатива — Cloudflare Worker + GitHub Pages

Если хотите статику на GitHub Pages, а прокси в Cloudflare:

- Фронтенд (содержимое папки `kbzhu/`) → GitHub Pages.
- [`worker/worker.js`](worker/worker.js) → Cloudflare Workers, секрет `DEEPSEEK_API_KEY` там же.
- В приложении в «Настройках» укажите адрес Worker `https://имя.аккаунт.workers.dev`.

---

## 🔑 Получение ключа DeepSeek API

1. https://platform.deepseek.com → войдите (или зарегистрируйтесь).
2. В левом меню **API Keys** → **Create API Key** → скопируйте ключ.
3. Ключ кладётся только в переменную окружения (`DEEPSEEK_API_KEY`) — в Render / `.env` / секреты Cloudflare — и не коммитится.

> Vision доступен на модели `deepseek-flash` (в проекте она стоит по умолчанию). Другие текстовые модели DeepSeek фото не принимают.

## 📦 Что куда выкладывать

| Что | Куда | Зачем |
|---|---|---|
| Весь код (папки `kbzhu/`, `server/`, `worker/`, `README.md`, `render.yaml`, `package.json`, `.env.example`, `.gitignore`) | **GitHub** | хранение исходников, откуда Render/Cloudflare берут код |
| `DEEPSEEK_API_KEY` (сам ключ) | **Render → Environment** (или Cloudflare Secrets / локальный `.env`) | секрет, в GitHub его нет |
| Запущенное приложение | **Render** (одна ссылка на всё) | сайт + API с одного адреса |
| `worker/worker.js` | **Cloudflare** (только если выбрали этот вариант) | прокси в DeepSeek вместо Render |
| `.env` (с настоящим ключом) | **только ваш компьютер** | локальный запуск, в git не попадает |

**Можно ли всё положить в GitHub?** Да — весь *код* можно и нужно положить в GitHub. Нельзя класть в GitHub только сам **ключ** (`DEEPSEEK_API_KEY`), потому что GitHub Pages не умеет хранить секреты и выполнять серверный код. Поэтому ключ и «живой» сервер живут на Render (или Cloudflare), а GitHub — это хранилище кода.

## Структура проекта

```
kbzhu/                    → фронтенд (статический PWA)
  index.html              → оболочка + meta PWA + splash
  manifest.webmanifest    → манифест установки
  sw.js                   → service worker (офлайн-кэш)
  icon.svg, icon-192/512.png, icon-maskable-512.png, apple-touch-icon.png
  css/style.css           → тема (светлая/тёмная), карточки, анимации
  js/app.js               → экраны, редактирование, дневник, история, статистика
  js/api.js               → вызов AI (автоопределение адреса сервера)
  js/store.js             → хранение (localStorage)
  js/nutrition.js         → пересчёт КБЖУ
server/index.js           → Node-сервер: статика + API → DeepSeek (без зависимостей)
worker/worker.js          → Cloudflare Worker (альтернатива серверу)
render.yaml               → деплой Render «в один клик»
package.json              → npm start
.env / .env.example       → ключ (локально) / образец
.gitignore                → защита ключа
```

## Возможности

- Камера и загрузка из галереи; сжатие фото до 1024px.
- Этапы анализа, индикатор уверенности 🟢/🟡/🔴 (общий и по продуктам).
- Редактирование: название, масса, Б/Ж/У; автопересчёт; «+ Добавить продукт».
- Уточняющие вопросы о размере порции, когда AI не уверен.
- Дневник (Завтрак/Обед/Ужин/Перекус) с целями и прогресс-барами.
- История с фото и удалением; статистика Сегодня/Неделя/Месяц.
- Светлая/тёмная тема; установка как приложение (PWA).

## Примечания

- Значения на 100 г приходят от DeepSeek (по справочным данным), итоги считаются в приложении.
- Модель по умолчанию `deepseek-flash`, меняется в `MODEL`.
- Данные (история, цели) хранятся в браузере устройства и не синхронизируются.
